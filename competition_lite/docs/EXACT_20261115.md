# Exact 内核与访问路径：实际 Git 镜像验收

本轮未修改 `lsm_store.hpp`。无过滤连续矩阵按批扫描，128 维 AVX-512 将查询向量扩展一次后复用；过滤候选默认两向量交错。只有距离有机会进入 Top-K 才读取真实行 ID，并列仍按主键排序。没有增加第二份向量缓存，也没有改变距离累加精度或可见性。

四向量和提前终止在默认输入上不划算，保留显式开关但默认关闭。`LITE_MATRIX_MB=0` 真正关闭矩阵。各 ISA 保持原双精度归约次序；标量与 AVX2 回退、非整组尾部和 mmap 换窗均有检查。

## 独立诊断与 I/O 限制

诊断同样固定 CPU 0/1，未用于上表计时。相对 32364de，无过滤访问/距离 0.264695→0.185545 ms，Top-K 0.024813→0.018407 ms；500 候选访问/距离 0.025631→0.020007 ms。完整距离和维度仍为 10000×128 与 500×128。首次准备和矩阵构建保存在 profile 的 warmup 记录，五段包含预热成本。

100 次提交诊断：向量同步 1 次自动 flush 屏障、4.048 ms，WAL 同步 100 次、245.750 ms；89990a8 则为 100 次/262.725 ms、100 次/269.077 ms。checkpoint 后续必要同步仍保留。BEGIN/语句整表复制统计仍为零。

写入区间成功 write/pwrite 字节：向量 5,120,000；WAL 7,099,380；SST flush 1,894,619；Manifest 167。此区间没有实际 compaction 或事务临时文件输出。相对 32364de 均未变化；相对 89990a8 多出 5,126,300 B WAL，仍是持久化优化的代价。rootless cgroup 未委派 io 控制器，**实际设备读写量不可用**；进程 write_bytes、逻辑写入和最终文件大小分别记录，不能相互替代。

## 验收与追溯

运行时 1796 物理行。实际 Git 镜像公开 20、补充 12、边界 13、Exact 1470、新内核路径 864、内核数值 300000、原提交故障 13、LSM 故障 42、损坏检查 8、冷模型 180、向量 WAL 故障 72 全部通过。内核包含 long double 独立真值、逐位比较、极值、非对齐指针、阈值上下相邻值；路径覆盖事务内更新、回滚、删除、重启和 1 MiB mmap 换窗。

两种旧格式迁移通过；150000 行单事务、约 398 MiB 文件在 128 MiB/no swap 下提交/查询/恢复通过。非 PIE ASan/UBSan 的模型、两套 Exact、内核与完整向量 WAL 故障全部通过。非 PIE 仅用于诊断，发布编译参数不变。公开及本地通过不保证隐藏门槛，未消耗官方提测机会。
