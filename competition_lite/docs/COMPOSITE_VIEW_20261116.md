# 综合指标：复用连续向量文件页

以 830fbba 为基线，连续向量复用 mmap，避免重复复制 5120000 bytes 到堆。保留紧凑编码和原 double 复核；主要收益是降低内存，没有实现 3/5/10 倍端到端加速。

## 实现与安全边界

Matrix 保存物理起点与长度，不持久保存 mmap 指针。仅在全部物理槽位连续、长度安全且映射成功时借用；每次查询重新获取完整映射，距离扫描期间不触发其他映射。结果投影可以重新映射，下一次查询重新取指针。Block 不借用整段矩阵。非连续更新/删除、多向量列交错、映射失败沿用复制或原读取。`LITE_MATRIX_VIEW=0` 恢复复制对照。

沿用更新、删除、回滚、失败语句、表/列切换、GC 的缓存失效规则。首个物理记录更新后，剩余记录和新版本仍可能连续；不能假定每次 UPDATE 都必须回退。新增 matrix_owned_bytes/matrix_mapped 诊断。默认矩阵副本从 5120000 降到 0 bytes，2600000 bytes 筛选数据保持。
