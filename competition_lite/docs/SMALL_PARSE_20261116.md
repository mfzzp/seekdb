# 默认小负载第二项：向量数值解析

本轮从已推送的 2373bf1 继续，只替换向量数字的常规十进制转换路径。C++ from_chars 先解析为 double，再沿用原来的 float32 转换、有限值、字符、分隔符和维数检查。前导加号或转换返回错误时回退 strtod，以保留正号、范围和下溢处理；`LITE_FAST_PARSE=0` 关闭。仍然每向量解析一次，没有把此前已经消除的重复解析再算一遍收益。距离内核和累积精度、WAL、每批提交、发布屏障、SST/Manifest 均未改。

选型时核对了 [C++ numeric conversion 规则](https://eel.is/c++draft/charconv.from.chars)：from_chars 不直接接受开头的加号，超出可表示范围返回错误，因此保留原实现回退。没有将这两个 API 的全部边界行为直接视作等价，而是另做字节兼容和错误检查。
