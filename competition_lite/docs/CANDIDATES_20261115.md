# 候选路径与综合验收（2026-11-15）

本轮正式运行时只增加连续过滤区间扫描：过滤结果的物理矩阵位置已经排序、唯一且形成连续区间时，复用现有矩阵内核，从该区间的真实物理起点开始。不会扩大候选集、跳过剩余谓词或改变距离和并列排序。非连续候选继续已有访问方式，Block 仍显式选择。`LITE_CONTIGUOUS_SCAN=0` 可关闭对照。

本轮保留这项范围查询改善。默认混合查询没有明显提速，不把所有此前优化的累计收益归给这十行改动。更早的 bitmap/sort 两个候选都撤回，失败证据同样归档。几何 Block 在独立实验中验证，不进入本次运行时。

相同向量与查询，仅过滤改为 10/1000/8000 候选，各组 60 条、五轮：

8000 候选约快 4.9%，1000 候选约快 3.2%；小候选略慢，不能称为普遍提速。开发期独立诊断确认连续扫描实际命中且矩阵扫描数恰为 10/1000/8000；8000 距离由关闭时 0.182707 降到 0.153557 ms，但准备仍约 0.26 ms。正式五轮端到端结果才用于保留决策。

之前 bitmap 实验的最终 Git 镜像正确性全过，但默认平均 0.275054→0.290630 ms、8000 组 0.582264→0.618443 ms，已撤回。后续实际计数发现 bitmap 命中始终为零：原始装载按 ID 排列，这些候选本来有序。此前将准备耗时下降归因于 bitmap 的说法错误，已在连续日志撤回；原始数据、源码差异和失败 gate 一并保留，未推送变慢的运行时。
