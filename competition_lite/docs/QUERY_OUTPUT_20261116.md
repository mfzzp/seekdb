## 实现与范围

原输出器为每个 double 创建 ostringstream，数组/对象递归返回临时字符串；热查询组装行数组、整份结果与 metrics 时存在深拷贝。新输出器递归追加到同一预留容量的字符串，double 使用 general/17 位 to_chars，并保留整数与 double 类型区别（需要时追加 .0）、有限值拒绝、字段顺序和原字符串转义。结果行预留容量，通过移动交给最终响应。

LITE_JSON_FAST=0 使用完整旧输出器，结果移动仍保留，便于隔离编码收益。距离内核、累积精度、候选集、排序规则、缓存预算、协议和持久化路径未改。该优化适用于实际返回内容，不缓存查询答案。新增 json_output_check.cpp，并将其接入后续 Docker gate。
